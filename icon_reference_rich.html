Using these in your app

This file is fully portable — copy it anywhere and open it; it only needs an internet connection. All icons load from the Iconify CDN (200k+ open-source icons, one script tag). Add <script src="https://unpkg.com/iconify-icon"></script> then use <iconify-icon icon="fluent-color:database-24" width="32"></iconify-icon>. React/Vue: npm i @iconify/react → <Icon icon="fluent-color:database-24" />.

Lucide icons are monochrome — color them with CSS: <iconify-icon icon="lucide:play" style="color:#059669"></iconify-icon>. The color sets (FC / F8 / 3D) have color baked in and cannot be recolored with CSS (use filter: hue-rotate() for tints, or edit the SVG for exact palette changes).

Need the raw SVG to bundle offline? Fetch https://api.iconify.design/fluent-color/database-24.svg or https://api.iconify.design/lucide/play.svg?color=%23059669 (works for any icon name shown here).
